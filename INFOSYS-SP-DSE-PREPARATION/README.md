# INFOSYS-SP-DSE-PREPARATION

Structured, self-contained prep material for the Infosys **Specialist Programmer (SP)** and **Digital Specialist Engineer (DSE)** hiring process — 2026 batch.

This repo is built so that no supplementary source is required mid-prep: syllabus, coding-round topic breakdown, previous-year-question patterns, and interview prep are all here in full.

## Structure

| Folder | Contents |
|---|---|
| [`01-overview/`](01-overview/) | What SP and DSE actually are, how they differ, salary bands, hiring stages |
| [`02-syllabus-and-pattern/`](02-syllabus-and-pattern/) | Exam pattern, timing, cutoffs, round-by-round breakdown |
| [`03-coding-topics/`](03-coding-topics/) | Full topic checklist by difficulty (Easy / Medium / Hard) with what to master in each |
| [`04-previous-year-questions/`](04-previous-year-questions/) | Previous-year coding question patterns, paraphrased with approach notes (not verbatim reproductions) |
| [`05-interview-prep/`](05-interview-prep/) | Technical interview question bank (DSA, OOP, SQL, system design, resume-based) + HR round prep |
| [`06-resources/`](06-resources/) | External sources used to compile this repo, plus a GitHub repo and YouTube playlist worth following |

## How to use this repo

1. Start with `01-overview` and `02-syllabus-and-pattern` — 15 minutes, gives you the shape of the whole process.
2. Work `03-coding-topics` top to bottom, Easy → Hard. Don't skip to Hard early; the coding round always includes at least one Easy and one Medium question.
3. Use `04-previous-year-questions` for pattern recognition, not memorization — Infosys reuses *patterns*, not exact problems.
4. Once you're clearing mock coding rounds consistently, move to `05-interview-prep`.
